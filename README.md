# Advance-Bank-Loan-Project-
A Bank Loan Data Analysis dashboard built using Power BI. It features a three-tiered interactive report (Executive, Overview, Detailed) to track 38.6K+ loan applications. Includes live KPI monitoring (Total Funded/Received, Avg DTI, Interest Rates), Good vs. Bad loan segmentation (86.2% vs 13.8%), and dynamic MoM and MTD performance insights.
