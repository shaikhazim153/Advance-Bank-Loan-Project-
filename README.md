## 📌 Project Overview

The **Bank Loan Analytics Dashboard** is a Business Intelligence project developed using Microsoft Power BI to transform raw loan data into meaningful financial insights.

The dashboard analyzes **38.6K+ loan applications** through three interactive report pages: Executive Dashboard, Loan Overview, and Detailed Analysis.

It enables users to monitor key performance indicators (KPIs), evaluate good and bad loans, track funded and received amounts, and analyze month-over-month (MoM) and month-to-date (MTD) performance.

## 📊 Key Performance Indicators

| Metric | Dashboard Result / Purpose |
|---|---|
| Total Loan Applications | 38.6K+ |
| Good Loans | 86.2% |
| Bad Loans | 13.8% |
| Total Funded Amount | Tracks total loan disbursements |
| Total Amount Received | Monitors repayments received |
| Average Interest Rate | Tracks the portfolio's average lending rate |
| Average DTI | Monitors the debt-to-income ratio |
| MoM Performance | Measures month-over-month changes |
| MTD Performance | Tracks month-to-date activity |

## 💡 Key Business Insights

- **Loan Portfolio Quality:** 86.2% of loans are categorized as good loans, while 13.8% are categorized as bad loans.
- **Funding Performance:** Total funded amount helps evaluate lending activity and disbursement trends.
- **Repayment Monitoring:** Total amount received provides visibility into repayments collected.
- **Interest Rate Analysis:** Average interest rate helps monitor lending trends.
- **Borrower Financial Profile:** Average DTI supports analysis of borrower debt obligations relative to income.
- **Time-Based Analysis:** MoM and MTD metrics help identify changes in lending performance.
